# Firespire web

Next.js 16 app (App Router, TypeScript) for Firespire. It reads the versioned artifacts generated by `pipeline/` and shows the fire history for Argentina. It is deployed on Vercel with this folder as the root directory.

## Commands

```bash
npm install
npm run dev      # development server
npm run build    # production build
npm run start    # serve the production build
npm run lint
npm test         # vitest run
npx vitest run lib/__tests__/<file> -t "<name>"   # single test
```

## Artifacts

The app reads artifacts from `public/artifacts/<version>/`, and `public/artifacts/latest.json` names the current version. Artifacts are generated by `uv run firespire build` in `pipeline/`. Vercel functions cap responses at 4.5 MB, so artifacts are served as static files, not through API responses.

`public/globe/` is the legacy static prototype, served at `/globe/index.html`.

## Contract

The data contract between pipeline and web is in [../docs/contratos.md](../docs/contratos.md). The artifact types are in `lib/artifact-types.ts`.

## Next.js 16

This version of Next.js has breaking changes compared with earlier releases. Read `AGENTS.md` in this folder before writing code. The framework's own docs are in `node_modules/next/dist/docs`.
